### 課程目標與定位

* **課程定位**：本課程定位為同時講述資安技術與基本概念，屬於「打底」的基礎課程。相較於另一門偏向治理層面的最佳實務課程，本門課更著重於教導實務上「怎麼做」。

### 課程大綱與重要主題

* **管理框架**：探討資訊安全管理制度，涵蓋 ISO2701 框架的應用。


* **技術佈局**：介紹零信任架構。探討如何透過零信任架構來落實資安防禦。


* **法規遵循**：重點介紹資安法與個人資料保護等相關法規。課程中也將探討國外 AI 法律的發展趨勢。


* **實務檢測**：包含滲透測試與弱點掃描。針對應用程式安全弱點進行檢查與因應。


* **事件與風險管理**：涵蓋資安事件的收集與分析。學習風險管理與意外事件的應對與回應。


* **新興議題**：探討雲端與供應鏈安全。特別強調新興科技的資訊安全設計與要求。
